# ChaosRL UI Decision Log

This log documents every architectural, design, and data representation decision made during the development of the ChaosRL presentation user interface.

| Decision ID | Date & Time | Context & Question | Decision Taken | Rationale & Alternatives Considered |
|---|---|---|---|---|
| DEC-UI-001 | 2026-10-29 03:00 | Project Directory Isolation | Confine all UI source code, build scripts, tests, data files, and documentation strictly to `ui/`. Zero alterations to root files (`src/`, `docs/`, `audit/`, `results/`). | Adheres strictly to audit integrity constraints. The UI is a pure presentation layer viewing the frozen project. |
| DEC-UI-002 | 2026-10-29 03:00 | Result-Set Selector Architecture | Build dual-cohort support directly into the data layer (`pre_audit.json` for original $n=10$ run, `post_audit.json` for extended audited $n=30$ run). Default the UI to the Audited Run ($n=30$) with clear toggles in the header. | Evaluators must be able to verify both the original paper claims and the higher-powered post-audit conclusions side-by-side with full transparency. |
| DEC-UI-003 | 2026-10-29 03:00 | Damage Metric Skew Contextualization | Add explicit contextual framing to the collateral damage charts and tables: Chaos Monkey only executes pod termination (1 of 4 fault modes), resulting in low recorded damage on multi-fault telemetry. Our learned agents explore latency, packet loss, and CPU stress, yet achieve $53.3\times$ lower damage than unconstrained random exploration (`random_all`). | Avoids misleading viewers regarding safety. When compared like-for-like against agents exploring the full multi-fault space, ChaosRL is vastly safer. |
| DEC-UI-004 | 2026-10-29 03:00 | Headline Model Feature Selection | Prominently feature TreeRanker (C12) as the primary ChaosRL Top-1 model ($2.38\times$ AUDC over Chaos Monkey, $p=0.0037$), and Heuristic Expert ($3.58\times$ AUDC, $0.2000$ recall) as the domain benchmark. | Highlights genuine, statistically proven wins without claiming unverified supremacy over heuristic methods. |
| DEC-UI-005 | 2026-10-29 03:00 | Scale and Budget Superiority Highlighting | Emphasize TreeRanker's performance on small-to-medium topologies ($N=20$: AUDC 0.2369 vs 0.2097 for Chaos Monkey) and low budgets ($B=25$: AUDC 0.0547 vs 0.0078, $7.0\times$ sample efficiency). | Shows exactly where reinforcement learning and ranking trees provide immediate practical value in CI/CD pipeline deployments. |
| DEC-UI-006 | 2026-10-29 03:00 | Pure Dynamic Insight Engine | Implement `src/insight/engine.ts` with programmatic rule-evaluation over data rows rather than hardcoded string messages. | Ensures the presentation is 100% data-driven, truthful, adaptable, and independently testable across different dataset slices. |
